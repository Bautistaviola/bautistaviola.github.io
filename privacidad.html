Política de privacidad

Aplicación: "Home Assistant" (uso personal de Bautista Viola) · Última actualización: 21 de noviembre de 2026

1. Quién usa esta aplicación

Esta aplicación es de uso exclusivamente personal. La utiliza únicamente su titular, Bautista Viola, para conectar su sistema de domótica Home Assistant con su propia cuenta de Google. No se ofrece a terceros.

2. Qué datos se acceden

Con la autorización del titular, la aplicación accede a la API de Google Calendar para leer y, si se configura, crear o modificar eventos de los calendarios de su propia cuenta.

3. Para qué se usan

Los datos del calendario se usan solamente para mostrarlos en el panel de control del hogar y para automatizaciones domésticas del propio titular (por ejemplo, avisos sobre eventos del día).

4. Dónde se guardan

Los datos se procesan y almacenan únicamente en el servidor Home Assistant instalado en el domicilio del titular. No se envían a servidores de terceros, más allá de las propias comunicaciones con los servicios de Google.

5. Compartir y venta de datos

Los datos no se venden, no se comparten con terceros y no se usan con fines publicitarios ni para entrenar modelos de inteligencia artificial.

6. Uso de datos de Google

El uso y la transferencia de la información recibida de las APIs de Google cumplen con la Política de Datos del Usuario de los Servicios de las APIs de Google, incluidos los requisitos de uso limitado.

7. Revocar el acceso

El acceso puede revocarse en cualquier momento desde myaccount.google.com/permissions o eliminando la integración en Home Assistant.
